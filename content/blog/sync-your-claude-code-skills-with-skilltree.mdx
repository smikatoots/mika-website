Nicolas and I constantly Airdrop .md skill files back and forth to keep our Claude Code skills in sync. So we built a lil something...

Our old workflow: I update a skill. Nick's still running the old version. We get different outputs. 10 minutes of "wait, which version are you on?" followed by an AirDrop & a prayer. The alt was version control with Github but it was annoying to push and pull with every file change. 

So we built SkillTree: a desktop app that detects every skill on your machine, puts them in one view across tools (Claude Code, Cursor, Codex), and syncs changes to a shared workspace so you're always using the same version.

It was a fun, quick project we built because we needed it. 

But if your team shares skills across roles, you've probably hit the same wall. So we're putting it out there in case it's useful! 

Link in comments & let us know if you want to learn more :)
